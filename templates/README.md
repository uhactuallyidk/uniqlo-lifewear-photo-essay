# เทมเพลต Digital Storytelling Project

โฟลเดอร์นี้รวม **แม่แบบสำหรับจัดทำ Report และ Slides** ในรายวิชา BS932116 โดยปรับจากเทมเพลตของอาจารย์และคงสาระที่จำเป็นไว้ ใช้กับโครงงาน Digital Storytelling ได้หลายรูปแบบ

| ไฟล์เทมเพลต | ใช้สำหรับ |
|---|---|
| [Digital_Storytelling_Report_Template.md](Digital_Storytelling_Report_Template.md) | ร่างรายงาน 6 บท ครบ 34 หัวข้อ รวม 5.6 พร้อมคำนำ บรรณานุกรม และภาคผนวก ก–จ |
| [Digital_Storytelling_Slides_Template.md](Digital_Storytelling_Slides_Template.md) | วางเนื้อหา 14 สไลด์หลัก พร้อมช่องกรอก แนวจัดวาง ภาพหรือหลักฐาน Speaker notes และเวลาพูดรวม 9 นาที |

## วิธีใช้

1. ทำสำเนาเทมเพลตที่ต้องการใช้ แล้วตั้งชื่อเป็นโครงงานของตนเอง
2. เติมช่อง `[กรอก…]` และแทรกภาพหรือหลักฐานตามคำแนะนำเฉพาะหัวข้อ
3. ระบุข้อมูลจริง สมมติฐาน แผน และสิ่งที่ยังไม่ได้ดำเนินการให้ชัดเจน
4. ลบส่วนคู่มือและคำแนะนำที่ระบุให้ลบก่อนส่งงาน

ไฟล์สองรายการนี้เป็น **ตัวเทมเพลตสำหรับนำไปกรอก** ส่วนร่างโครงงาน UNIQLO LifeWear อยู่ที่ [หน้าแรกของ repository](../README.md)
