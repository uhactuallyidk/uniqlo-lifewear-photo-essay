# Template รายงาน Digital Storytelling Project

## คู่มือใช้เทมเพลต — ลบส่วนนี้ก่อนส่งรายงาน

เอกสารนี้เป็นเทมเพลตกลางสำหรับรายวิชา **BS932116 การเล่าเรื่องสำหรับการสื่อสารทางดิจิทัล** รองรับวิดีโอ ชุดวิดีโอสั้น Podcast / Audio Story, Photo Essay, Infographic / Data Storytelling, Social Media Content Series, Interactive Story และรูปแบบอื่นตามโครงงาน

### วิเคราะห์ต้นฉบับและเหตุผลที่ปรับ

ต้นฉบับมีหัวข้อครอบคลุมงาน แต่ช่องเติมประโยคสั้นทำให้ผู้เขียนตอบเป็นรายการโดยไม่ได้อธิบายเหตุผล หัวข้อกลุ่มเป้าหมาย รูปแบบสื่อ แพลตฟอร์ม และสารหลักปรากฏหลายครั้ง จึงเกิดการเขียนซ้ำได้ง่าย ตารางบางส่วนแยกข้ามหน้า และข้อความคำสั่งปะปนกับเนื้อหารายงาน

โครงใหม่นี้คงเลขหัวข้อเดิมเพื่อให้อาจารย์ตรวจได้ แต่ให้แต่ละส่วนทำหน้าที่ชัดเจน: อธิบายบริบท ระบุเหตุผล แสดงสิ่งที่ทำจริง และแนบหลักฐาน เมื่อข้อมูลซ้ำ ให้สรุปเฉพาะจุดที่เกี่ยวข้องแล้วอ้างกลับไปยังหัวข้อหลัก

**จุดที่แก้เพิ่ม:** สารบัญ PDF มีหัวข้อ 5.6 การประเมินคุณภาพผลงานของกลุ่ม แต่เนื้อหาต้นฉบับไม่มีส่วนให้กรอก จึงเพิ่มส่วนนี้ตามสารบัญ โดยเกณฑ์ประเมินในเทมเพลตเป็นแนวทางที่เสนอ ไม่ใช่เกณฑ์คะแนนที่อาจารย์ประกาศ

### วิธีกรอกและสถานะข้อมูล

- แทนที่ `[กรอก…]` ด้วยข้อมูลของกลุ่ม และแทนที่ `[แทรกภาพ…]` ด้วยภาพจริงพร้อมคำบรรยายและที่มา
- ข้อความใน blockquote ที่ขึ้นต้นว่า **คำแนะนำ — ลบก่อนส่ง** เป็นคำสั่งสำหรับผู้เขียน ให้ลบหลังกรอก
- คงทุกหัวข้อไว้ หากไม่เกี่ยวข้อง ให้เขียน `ไม่เกี่ยวข้อง: [เหตุผล]` และระบุทางเลือกที่ใช้แทนถ้ามี
- ระบุสถานะข้อมูลตามจริง: **ข้อมูลที่ตรวจสอบแล้ว / สมมติฐาน / แผน / ดำเนินการแล้ว / ยังไม่ได้ดำเนินการ / ยังไม่มีข้อมูล**
- Insight ต้องมีที่มา หากยังไม่มีการศึกษาผู้ชม ให้เรียกว่า “สมมติฐานเกี่ยวกับผู้ชม” Persona ต้องระบุว่าอ้างอิงข้อมูลจริงหรือเป็น Persona สมมติ
- ผลตอบรับต้องระบุจำนวนผู้ให้ข้อมูล วิธีเก็บ และช่วงเวลา ห้ามเติมยอดรับชม คำพูด หรือผลทดลองที่ยังไม่เกิดขึ้น
- วัตถุประสงค์คือสิ่งที่ต้องการให้เกิด ส่วนผลลัพธ์คือสิ่งที่มีหลักฐานว่าเกิดขึ้นแล้ว เขียนแยกกัน
- ช่องแพลตฟอร์มและตัวชี้วัดเลือกเฉพาะที่เกี่ยวข้อง ไม่จำเป็นต้องกรอกทุกแพลตฟอร์มหรือใช้ทุกตัวชี้วัด
- ไม่กำหนดความยาววิดีโอหรือจำนวนฉากขั้นต่ำเพิ่มเติม เพราะ PDF สองไฟล์นี้ไม่ได้กำหนดเป็นเงื่อนไขตายตัว

### โครงเหตุผลที่ใช้ตลอดรายงาน

ให้ผู้อ่านตามได้ว่า **ประเด็นนี้สำคัญกับใคร → ผู้ชมต้องการอะไร → เลือกเล่าแบบใดและเพราะอะไร → ผลิตอย่างไร → ได้ผลงานและหลักฐานอะไร → เรียนรู้อะไร** ใช้โครงนี้ตรวจความเชื่อมโยงของเนื้อหา ไม่ต้องคัดลอกประโยคนี้ลงรายงาน
